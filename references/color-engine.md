# Color Engine —— 色彩层级引擎

> **少色相、多色阶；少纯色、多表面；有主次、有温度、有明暗。**
>
> 用户说"颜色太素"，真正的病因从来不是"颜色少"，而是**缺少色彩层级**：
> 纯白底 + 纯黑字 + 一个主色 + 一个强调色，四个颜色各自为战，没有家族关系。
> 页面看着"高级又丰富"的课件，往往只有 2–3 个色相——但每个色相都有自己的明度阶梯，
> 底、卡片、标题、数字各来自不同档位。丰富来自**层次**，不来自**数量**。

来源：Frontend Slides（色阶系统 + Warm Paper）、MiniMax（成套 Palette Library）、
Anthropic（Dominance over equality：一个颜色占 60–70%）、DeerFlow（氛围背景，只取"深浅"不取特效）。

---

## 一、Tonal Scale：一个色相，11 个档位

每个家族的主色都是一个种子（HEX），由 `scripts/lib/palette.js` 展开成 11 档。
种子色基本落在 **700 档**——"我选的颜色"真的出现在标题里，不是被调淡一档。

| 档 | 角色 | 档 | 角色 |
|---|---|---|---|
| 950 | 封面 / 章节页 / 结论页深底（deep） | 500 | 图表第二系列、强调条 |
| 900 | 深色页第二层面板（deepAlt） | 400 | 图表第三系列 |
| 800 | 深底上的标题与线框 | 300 | 图标线条、进度 |
| 700 | **内容页标题（primary）** | 200 | 卡片底、信息区（surfaceAlt） |
| 600 | 主色块、图表第一系列、图标 | 100 | 浅底信息区、标签底（primarySoft） |
| | | 50 | 页面底与纸白的过渡（veil） |

生成规则（写死在引擎里，不要手调）：

- 明度阶梯固定；深端（600–950）围绕种子明度展开，浅端（50–400）固定。
- 饱和度按档收敛：越靠两端越灰（纯饱和的浅绿/深蓝都会"脏"）。
- 最浅三档往 paper（纸白）混合——所以浅色是"暖的浅"，不是"灰的浅"。

**禁令：不要用 `shade()` 手动调亮调暗来造色阶**——深色端会压成脏黑。要用 `theme.tone[档位]`。

---

## 二、Surface System：三层表面，永远不用纯白

"素"的第二病因是 `#FFFFFF` 底。纸要有温度：

| token | 层 | 约束 |
|---|---|---|
| `bg`（canvas） | 页面底 / 大留白 | 带色温的暖白（C01–C09 全部偏黄或偏粉），**禁止 #FFFFFF** |
| `veil` / `veilDeep` | 版心薄雾 | 比 bg 深半档，用来分出版心 |
| `surface` | 卡片 / 面板 | 比 bg 亮一档（混白 70%），但仍是暖色，不是纯白 |
| `surfaceAlt` | 第二信息层 | 微带主色（混 tone600 10%），卡片分区靠它 |

三层表面 + 阴影 = 卡片"浮"在纸上；纯白底上的白卡片只能靠描边活着。

---

## 三、Accent System：强调是撒盐，不是倒酱油

- 强调色**面积 ≤10%**（Anthropic 的 Dominance over equality：一个颜色要占 60–70%，
  强调色是"3–5% 的盐"）。超了不是丰富，是花。
- 强调色三件套已在主题里：`accent`（本色）/ `accentLight`（金线亮端）/ `accentDeep`（暗端）。
  装饰线不做纯色——三段渐变才有"描金"的分量。
- `accentText` 是引擎算好的安全强调字色（对 bg ≥4.5:1），大字/数字用它，别直接用 accent。

---

## 四、Semantic Color：语义色从家族内部推导

主题自带 `sem`：`pos`（对）/ `neg`（错）/ `warn`（警示）/ `info`（参考）。
它们由主色阶与强调色混合生成，**不引入第 4 个色相**。

规则：语义色只出现在**小面积标记**——勾叉图标、1px 描边、判定标签。
不要给"正确答案"铺一大块绿、错误铺一大块红，那是对比页最常犯的错；
对错对比靠 debate 版式的左右分栏 + 小标记完成。

## 五、配比卡（每套色族自带的目标面积）

```

主色色阶（含 950 深底）  #6E2233  22%   700 做标题，600/500 做块
浅主色 / 信息区         #E7D1CA  10%   100/200 档
强调                   #B08A4E   5%   数字 / 关键线 / 图标
```

### C10：从参考 PPT / 学校 VI 提取

不是吸一个 HEX 就用。四个角色分开取，再展开成完整色阶：

```
python scripts/dna.py 参考.pptx            # 读出调色板（面积占比）
node scripts/palette.js from F7F0E4 6E2233 B08A4E 2A1A1C
#   ↑ 纸白        主色     强调     墨色 → 输出可直接用的 family JSON
```

- 纸白取**最亮**的（且不是纯白）；墨色取**最暗且低饱和**的；
- 主色取**饱和且偏暗**、面积大的；强调取与主色色相错开 ≥25° 的亮饱和色。
- 提取完必须过 `palette.audit`（对比度 / 纯白 / 面层 / 明暗差四类自检）。

## 七、Contrast QA：色彩层级的量化验收

**构建期**（每次 resolve 主题都会跑）：`palette.audit(theme)`——
正文/标题对比度、纯白底、纯黑字、面层缺失、深浅差不足，五类问题直接报。

**成品期**（整册统计）：`python scripts/colorqa.py deck.pptx`

| 项 | 阈值 | 含义 |
|---|---|---|
| HUE | 饱和色相 >4 warn / >5 error | "花"的直接来源 |
| DOMINANT | 最大家族占饱和色 <35% warn | 没有主导色，画面散 |
| CANVAS | 页面底出现 #FFFFFF/#000000 warn | "素"的直接来源 |
| SURFACE | 中性面层只有 1 种 info | 卡片与底没有层次差 |
| TONAL | 主色相明度档 <3 info | 色阶没有用起来 |
| ACCENT | 次色相占饱和色 >12% warn | 强调变主流 |

文字按字符量 × 字号² 估算权重；照片不参与统计（照片的色相不代表配色纪律）。

## 八、氛围与背景（学 DeerFlow 的"深浅"，不学它的特效）

- 封面 / 章节页 / 结论页走 **950 档深底**（`deep` / `deepAlt` 双层 + `deepGlow` 微光），
  深浅对比就是氛围——不需要 mesh gradient 和玻璃拟态。
- 深底上的文字用 `deepInk`（暖白）与 `deepMuted`，禁用纯白。
- **禁止"AI 紫渐变"**：全册氛围来自色温与明暗节奏，不来自荧光渐变与模糊光斑。
- 内容页永远是纸白底 + 三层表面；深底只出现在节拍页（约每 8–12 页一次）。

## 九、反模式清单（出现即重做配色层）

1. 页面底 #FFFFFF、正文 #000000 —— 画面没有温度，先换纸白和暖黑。
2. 一页出现 5 个以上互不相干的彩色 —— 收敛到 2–3 个色相，靠色阶分工。
3. 强调色大面积铺满 —— 强调 ≤10%；要面积就把档位降到 100/200（变成信息区）。
4. 所有彩色都取自同一个明度 —— 层级消失；标题 700 / 色块 600 / 浅底 100 各就各位。
5. 手写 HEX 造色 —— 一切颜色来自 theme token / tone 档位，保证全册一致。
6. 从参考 PPT 抄 logo、照片和成组装饰 —— C10 只提取四个种子色，"学习 ≠ 复制"。


## 页内强调层级（1.4.1）

色阶解决"整册有层次"，页内强调解决"一页里看不出重点在哪"。
规则：**重点不是靠加粗，是靠颜色——普通文字是墨色，重点才是主色。**

### 1) 文本标记（写 deck spec 时直接用）

```json
{ "body": "职权分为**直接影响组织方向**的力量，其中!!决策权!!最关键" }
```

- `**关键词**` → 主色加重（`em`，对页底 ≥4.5:1）——正文里的关键名词、术语
- `!!焦点!!` → 强调色加重（`emAccent`）——一页最多一处，留给全页唯一的焦点词
- 标记对 `title` / `body` / `insight` / 列表项全部生效；测量按剥掉标记的纯文本计算，不会算宽
- 深色卡、深色页上自动换 `emOnDeep` / `accentOnDeep`（同样 ≥4.5:1），不用手工挑色

### 2) 强调卡（bento）

```json
{ "layout": "bento", "cells": [ { "title": "直线职权", "em": true, ... }, ... ] }
```

- `em: true`（或 `tone: 'tint'`）→ 主色浅底 + 主色描边 + 主色强调条 + 主色标题 + 深色徽章
- **一页最多一张**——强调卡一多，"哪张是重点"就又被抹平了

### 3) 其他自动生效的强调位

- 页底结论条（insight）：主色浅底 + 主色正文，是"每页的落点"，不再和白卡平权
- bento 序号：实底圆徽章（强调卡=主色底纸白字，普通卡=强调色底深墨字）
- KPI 大数字：主色（已经是）

### 4) 纪律

- 每页强调面积 ≤ 页面 25%（一张强调卡 + 一条结论条已是上限）
- `!!` 焦点每页 ≤1 处；`**` 每段 ≤1 处——全是重点等于没有重点
- 强调色一律来自 token（em/emAccent/emOnDeep），禁止手写 HEX
