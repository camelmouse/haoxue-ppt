# 第 5 层｜设计引擎：Design DNA

用户最常说的话是："这个 PPT 是别的专业的，学它的设计和结构，但不要照搬内容。"
这一层把"看一下、学一学"变成可执行的六维参数。

---

## 一、六维 DNA

| 维度 | 抽什么 | 迁移到本 skill 的哪 |
|---|---|---|
| **视觉** | 底色、主色、强调色、用色数量、深色页占比 | `theme`（就近映射到 10 套内置主题） |
| **版式** | 页面类型分布、版式指纹种类 | `layout-library.md` 的页面配比 |
| **字号** | 标题/正文/最小字号、层级比、字体 | `TYPE` 六级阶梯（**不迁具体磅值**） |
| **密度** | 每页字数中位数、最挤的页、超密页 | 拆页决策、`DENSITY_MAX` |
| **图片** | 有图页占比、图占版面比、全出血页数 | 图片模式、是否走无图结构 |
| **叙事** | 字数曲线、节拍页位置与间隔 | 节奏设计（每几页停一次） |

抽法：

```bash
python scripts/dna.py 参考.pptx                    # 打印报告
python scripts/dna.py 参考.pptx --json out/dna.json # 存成参数，供后续比对
```

输出示例（实测）：

```
底色 F0EEE9  主色 896438  强调 B4834A  用色 4 种
标题 42pt / 正文 16pt / 最小 16pt   层级比 2.62
4 类：纯文字×5、卡片网格×4、图表页×1、图文左右×1   版式指纹 10 种
平均 197 字/页，最挤 P9（329 字）
节拍页：第 1、2、5、6、9、11 页，平均每 2.1 页一次
配色可映射到主题 slate（墨岩金）
```

读这份报告的顺序：**先看节拍页间隔，再看版式指纹数，最后才看配色。**
节奏是骨架，配色只是衣服。

## 二、学习 ≠ 复制

| 可以迁（结构与判断） | 不要迁（身份与素材） |
|---|---|
| 页面类型配比（几页图文、几页图表） | logo、校徽、机构标识 |
| 节拍间隔（几页停一次） | 人物照片、产品图、客户案例图 |
| 图文比例、留白比例 | 成组的几何装饰（那是它的品牌语言） |
| 标题长度与句式 | 它具体的色值（色值跟着它的品牌走） |
| 图表与结论的对应关系 | 它的母版、页脚、页码样式 |

一句话：**迁"为什么这样排"，不迁"它长什么样"。**

复制配色是最常见的偷懒：把参考 PPT 的深蓝直接拿来用，结果和你的内容气质不搭
（管理课配了一份金融年报的蓝）。正确做法是让 `dna.py` 映射到内置主题，再微调强调色。

## 三、Show, Don't Tell：三个真实方案

不要问用户"你喜欢简约还是商务"——这个问题对任何人都没有意义。
用**他的真实内容**做三个方案，让他指。

| 方案 | 做法 | 适合 |
|---|---|---|
| **A 稳** | 内置主题（如 `academic` 学术青橙）+ 卡片网格为主 + 少量图 | 常规课时、评审听课、要"不出错" |
| **B 视觉** | 大图 + 强标题 + 高对比（`fullImage` / `offsetImageText` / `bigIdea` 为主） | 开场、公开课、需要抓注意力 |
| **C 实验** | 数据/矩阵/对照为主，接近信息设计或杂志排版（`matrix` / `dataChart` / `debate`） | 案例分析课、研讨课、高年级 |

做法：用同一页内容（通常是案例开场页或核心概念页）生成三版缩略图，
让用户指一个，然后再铺全套。

```bash
node scripts/build.js <spec> -o out/A.pptx --theme academic
node scripts/build.js <spec> -o out/B.pptx --theme darktalk --image image-first
node scripts/build.js <spec> -o out/C.pptx --theme editorial
python scripts/render.py ... && python scripts/sheet.py ...   # 拼成一张对比图
```

三个方案必须**同内容、不同结构**。只换配色不算三个方案。

## 四、DNA → 参数的映射规则

| DNA 观察 | 落到参数 |
|---|---|
| 深色底占比 >30% | 考虑 `tech` / `darktalk`；卡片阴影自动关闭 |
| 强调色饱和度很高（>0.6） | 降一档饱和度再用；高饱和在投影上会刺眼 |
| 最小字号 <16pt | **不要跟**，本 skill 下限 16pt |
| 平均字数 >200 | **不要跟**，改成拆页 |
| 节拍间隔 <2 页 | 太碎，改成每 4–5 页一次 |
| 版式指纹 ≤2 种 | 它其实没有版式设计，学它的内容组织就好 |
| 有图页占比 >70% | 你未必有同等素材；先跑 `--image none` 看无图版撑不撑得住 |

## 五、常见误区

| 误区 | 后果 | 正解 |
|---|---|---|
| 直接套用它的母版 | 生成出来仍是它的品牌，你的内容像"借来的" | 只取结构参数，用本 skill 主题重建 |
| 抄它的装饰元素 | 元素与你的内容无关，变成噪音 | 装饰只保留"划分区域"和"标记层级"两类 |
| 学它的字号（正文 12pt） | 投影看不清 | 下限 16pt，层级用六级阶梯 |
| 学它的密度 | 一页塞三段 | 拆页 |
| 只看图不看结构 | 学了个壳 | 先跑 `dna.py`，读节拍与指纹 |

## 六、自查

- [ ] 跑过 `dna.py`，报告里的节拍间隔与版式指纹数说得出来
- [ ] 迁移清单里只有结构与节奏，没有素材与标识
- [ ] 配色是从内置主题映射的，不是直接取的色值
- [ ] 参考对象的具体字号/密度没有被照抄（尤其 <16pt 与 >200 字/页）
- [ ] 三个方案是同内容不同结构，不是同结构换配色
