# 教学页面库（13 类配方）

按"这页要干什么"选页面类型，再去 `layouts.md` 查字段。
**页面类型 → 版式 id** 是映射，不是等价：同一类页面在不同内容下可以换版式，但槽位不能少。

---

## 01 CaseOpening｜案例开场

- **认知动作**：`curiosity`
- **版式**：`caseStory`（有图）/ `bigIdea` + 图（无图）
- **槽位**：一句反差标题 + 具体的人与数 + 一个未解的疑问
- **禁忌**：开场就给结论；"某企业面临挑战"这种没有人的案例
- **例**：「酒店明明有空房，前台为什么不能免费升级？」

## 02 Conflict｜冲突（推翻误解）

- **认知动作**：`conflict`
- **版式**：`debate`（左右对照）/ `matrix` / `caseStory`
- **槽位**：多数人以为 X（左）｜实际情况 Y（右）｜一句"为什么我们会想错"
- **禁忌**：写成"注意区分 X 和 Y"，那是提醒，不是冲突
- **例**：「前台随意升级，为什么可能伤到整个酒店？」

## 03 Question｜互动提问

- **认知动作**：`prediction`
- **版式**：`question`
- **槽位**：真实情境 + 具体数字 + 3–4 个选项（错项要是真实误解）+ 正确答案
- **禁忌**：`以下说法正确的是 A/B/C/D`（考试题）；选项凑数
- **例**：「几十元的退款也要主管点头，如果你是老板，会怎么做？」

## 04 ConceptReveal｜概念揭示

- **认知动作**：`concept`
- **版式**：`layers`（定义/特征/边界三层）/ `bento`（并列特征）
- **槽位**：一句定义 + 2–3 个特征 + **一句边界**（什么时候不算）
- **禁忌**：只给定义不给边界；用流程图讲定义
- **例**：「职权是组织给的，不是个人挣的」

## 05 Compare｜对照辨析

- **认知动作**：`concept` 或 `conflict`
- **版式**：`debate` / `matrix`
- **槽位**：两个对象的**同一组维度**逐条对（维度必须对齐）
- **禁忌**：左边三条、右边五条（维度不对齐，读不成对比）
- **例**：「分权定格局，授权定动作」

## 06 Timeline｜时间线

- **认知动作**：`explanation` 或 `evidence`
- **版式**：`timeline`
- **槽位**：4–5 个节点，每个"时间 + 发生了什么 + 一句后果"
- **禁忌**：节点超过 6 个（挤成一排小字）；只有时间没有后果
- **例**：「一次免费升级，为什么会伤到整个酒店？」

## 07 Process｜流程/步骤

- **认知动作**：`application` 或 `concept`
- **版式**：`flow`（带产出标签）/ `layers`（分层）
- **槽位**：3–6 步，每步"动作 + 一句要点 + 产出/判断点"
- **禁忌**：超过 6 步（该合并或拆页）；只写动作名，不写产出
- **例**：「一次完整授权，要走六步」

## 08 Structure｜结构关系

- **认知动作**：`explanation`
- **版式**：`causalChain`（因果）/ `layers`（层级）/ `flow`（链条）
- **槽位**：3–4 环，每环一句话；因果链要标出终点（结果）
- **禁忌**：环数超过 4（读不完）；把并列关系画成因果
- **例**：「职能职权：专业部门凭什么管到别的部门？」

## 09 Evidence｜证据页

- **认知动作**：`evidence`
- **版式**：`dataChart`（+KPI）/ `caseStory`（案例结果）/ `zoom`（细节）
- **槽位**：一个结论式标题 + 图/数 + **一句"这组数字说明什么"**
- **禁忌**：图表没有结论；一页放两张无关图表；纵轴两位数刻度（部分渲染器会截）
- **例**：「依从性不是说服出来的，是触点养出来的」

## 10 StudentTask｜学生任务

- **认知动作**：`application`
- **版式**：`bento`（多任务）/ `question`（单选）/ `matrix`（分类任务）
- **槽位**：情境 + 任务（选一个做）+ **判断标准**（凭什么算对）
- **禁忌**：任务是"讨论一下"（没有产出）；不给判断标准
- **例**：「如果你是这家中心的负责人，先解决哪一个？」

## 11 Misconception｜误区清单

- **认知动作**：`conflict` 或 `explanation`
- **版式**：`bento`（3–4 条）/ `debate`（一对一错）
- **槽位**：误区原话（用学生的口气）+ 为什么错 + 正确做法
- **禁忌**：写成"常见错误：1. 2. 3."（没有解释为什么错）
- **例**：「知道该放权，为什么还是不放？」

## 12 Transfer｜迁移页

- **认知动作**：`transfer`
- **版式**：`debate` / `offsetImageText` / `matrix`
- **槽位**：换一个行业/角色/规模 + 同一条原理 + **一句"哪里不成立"**
- **禁忌**：只换名词不换情境（"另一个公司也这样"）
- **例**：「医院为什么不能照搬电商的审批？」

## 13 Summary｜收束

- **认知动作**：`reflection`
- **版式**：`summary`（3 条）/ `bigIdea`（一句）
- **槽位**：回到开场的问题 + 唯一记忆句（与 intent.oneLine 措辞一致）+ 课后一件事
- **禁忌**：把全课要点罗列一遍（那不是总结，是目录）；出现新的知识点
- **例**：「权力到底该怎样配置？」

## 一页课件的典型配比（90 分钟 / 18 页正文）

| 类型 | 页数 | 说明 |
|---|---|---|
| CaseOpening | 1–2 | 开场必须有一个具体的人 |
| Question | 1–2 | 先判断，答案压后 |
| ConceptReveal / Compare | 4–5 | 概念与辨析是主体 |
| Structure / Process | 3–4 | 机制与步骤 |
| Evidence | 1–2 | 一组数据或一个案例结果 |
| Conflict / Misconception | 2 | 推翻误解，至少一次 |
| StudentTask | 1 | 带判断标准 |
| Transfer | 1 | 边界 |
| Summary | 1 | 回到开场 |

**任何类型连续出现三页，节奏就会塌。** 类型轮换比版式轮换更重要。
