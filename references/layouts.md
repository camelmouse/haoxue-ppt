# 版式：先识别知识结构，再决定视觉布局

选版式的顺序永远是：**这段内容是什么关系** → 哪种图能表达这种关系 → 对应哪个版式。
不要反过来"今天想用时间轴，那内容怎么塞"。

---

## 一、知识结构 → 版式映射

| 这段内容在做什么 | 选它 | 不要选 |
|---|---|---|
| 一个必须被记住的判断，信息量小 | `bigIdea` | `layers`（会把一句话拆成三层废话） |
| 两种立场/两种方案要并置比较 | `debate` | `flow`（流程不能表达冲突） |
| 概念有层级（表层/机制/底层） | `layers` | `timeline`（层级不是时间） |
| 3–6 步操作、服务链路、实验步骤 | `flow` | `causalChain`（步骤不等于因果） |
| 有明确时间点的演化、病程、旅程 | `timeline` | `flow`（时间轴强调节点，流程强调动作） |
| A→B→C 的机制推演，最后落到结果 | `causalChain` | `timeline`（因果不是时间顺序） |
| 两个维度交叉定位（重要-紧急、渗透-复购） | `matrix` | `layers`（二维不能用层叠表达） |
| 需要数据说话：趋势、构成、对比 | `dataChart` | `matrix`（散点不等于统计图） |
| 有真实场景图，图文互证 | `offsetImageText` | `fullImage`（全幅页承载不了正文） |
| 图里有必须看清的细节（解剖/界面/报表） | `zoom` | `offsetImageText`（看不清细节） |
| 情绪或场景优先的过渡 | `fullImage` | 内容页 |
| 有过程、有转折的真实案例 | `caseStory` | `flow`（案例有情绪，流程没有） |
| 先让学生判断，再揭示答案 | `question` | `agenda`（不能代替互动） |
| 全课收束，≤3 条可复述 | `summary` | `bigIdea`（收束要落地，不只喊口号） |
| 今天走哪几条路 | `agenda` | `layers`（章节不是层级） |
| 换气、给课堂节拍 | `divider` | 硬切到下一页 |

## 二、18 种版式

| id | 名称 | 适合 | 关键约束 |
|---|---|---|---|
| `cover` | 封面 | 第 1 页 | 标题 ≤ 2 行（52pt 起，自动降到 34pt） |
| `agenda` | 课程导览 | 2–5 个章节 | 每项一行说明，不要写成目录树 |
| `divider` | 章节分隔 | 每 3–5 页一次 | 深底 + 96pt 数字，`desc` 一句 |
| `bigIdea` | 大字观点 | 一句话判断 | 全文 ≤ 60 字；用 `\n` 控断点更整齐 |
| `question` | 互动问题 | 先判断后答案 | 选项 3–4 个；题干含具体数字 |
| `debate` | 双方观点 | 立场对撞 | 左右各 3 条以内，`verdict` 必须有 |
| `layers` | 结构分层 | 表层/机制/底层 | 3–4 层；`title` 写判断句不写名词 |
| `flow` | 流程图 | 3–6 步 | 每步 `body` ≤ 2 行；`out` 是产出物 |
| `timeline` | 时间轴 | 4–6 个节点 | 标签是时间/阶段，不是序号 |
| `causalChain` | 因果链 | 3–4 环 | 最后一环 `hi:true` |
| `matrix` | 二维矩阵 | 分层/定位 | 四象限都要有名字，散点 ≤ 6 个；轴向只写"名字 + 方向"，不要四个方向标签各占一行 |
| `bento` | 卡片栅格 | 一主多辅的能力/指标 | `items` 3–6 个：3 = 一大两小，4 = 2×2，5 = 上二下三，6 = 3×2；`hi:true` 的那张占大格 |
| `dataChart` | 数据图表 | 趋势/构成/对比 | 一个图一个结论；KPI ≤ 3 个（16pt 下限下，3 组是上限，再多就换页） |
| `offsetImageText` | 错位图文 | 图文互证 | 图片 6.05×3.82，`points` ≤ 3 条 |
| `fullImage` | 全幅图片 | 过渡/情绪 | 一句标题 + 一句副文，不承载知识点 |
| `zoom` | 局部放大 | 解剖/界面/报表 | `r` 取 0.12–0.18；`notes` ≤ 3 条 |
| `caseStory` | 案例叙事 | 有转折的案例 | 四幕；理论面板 2–3 点 |
| `summary` | 极简总结 | 收束 | ≤3 条 + 下讲预告 |

导航：`cover` / `fullImage` / `divider` / `summary` 默认不画进度导航，其余页自动画。
需要单页关闭时写 `"nav": "hidden"`。

## 三、反模式（出现即返工）

| 反模式 | 为什么错 | 怎么改 |
|---|---|---|
| 连续 3 页三栏卡片 | 版面没有节奏，学生视觉疲劳 | 插入 `bigIdea` / `divider` / `zoom` |
| 每页都从"定义"开始 | 没有"与我有关"的入口 | 用 `question` 或真实案例开场 |
| 用 `layers` 讲流程 | 层级和顺序是两种结构 | 改 `flow` |
| 用 `timeline` 讲因果 | 时间先后 ≠ 因果 | 改 `causalChain` |
| 一页塞两个结论 | 学生一个都记不住 | 拆成两页，或只留一个 |
| `summary` 写 5 条 | 等于没有重点 | 压到 3 条以内 |
| 图表没有结论 | 学生看完不知道要干什么 | 加 `insight` 条 |
| 全幅图页放正文 | 字压在图上看不清 | 改 `offsetImageText` |

## 四、版式节奏模板（12 页参考）

```
01 cover            封面
02 agenda           今天走哪几条路
03 question         先判断（暴露误解）
04 bigIdea          核心命题（砸一下）
05 layers           机制分层
06 flow             怎么落地（5 步）
07 dataChart        数据说话
08 offsetImageText  真实场景
09 caseStory        完整案例
10 debate           两种方案对撞
11 summary          三句话收束
（divider 按章节数插入，每 3–5 页一次）
```

这套节奏对应示例文件 `examples/health-marketing.deck.json`（11 页，11 种版式），可直接改内容复用。
