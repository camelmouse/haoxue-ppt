# 第 4 层｜内容引擎（Content Engine）

这一层解决"材料从哪来、能不能用、怎么标"。
教学内容出问题，八成不是排版，是**素材不具体、来源不清、边界不明**。

---

## 一、四类素材，四种处理方式

| 素材 | 处理方式 | 判断能不能用 |
|---|---|---|
| **教材** | 提知识树 → 分必讲/可拓展/可删 | 这一段是"考点"还是"背景"？背景进讲稿 |
| **案例** | 四幕化（起点/转折/结果/回声） | 有没有具体的人、时间、数字？ |
| **数据** | 指向上一个结论 | 这组数字支持哪句话？说不出来就不用 |
| **图片** | 等比裁切、压字用渐变遮罩 | 这张图在承担"看见"还是装饰？装饰就删 |

---

## 二、教材 → 知识树

不要按教材的小节顺序做页。教材是**阅读顺序**，课堂是**理解顺序**，两者经常相反。

三步：

1. 把本章所有小标题列出来，写成"概念—关系—程序"三类（见 `cognitive.md` 的五类知识）。
2. 标三级：**必讲**（考点/后续课要用）、**可拓展**（有能力的学生加餐）、**可删**（教材的展开举例）。
3. 必讲部分排进六拍；可拓展的做成讲稿里的"如果学生问"；可删的直接不留。

判断"必讲"的一句话测试：**这一条不考、后面也不用，那这节课为什么讲它？**

---

## 三、案例：四幕与三个具体性

### 四幕结构

| 幕 | 内容 | 常见错误 |
|---|---|---|
| 起点 | 具体的人、时间、数字、处境 | "某企业面临挑战"（没有人和数） |
| 转折 | 做了某个动作（或没做），情况变了 | 直接给结果，跳过了决定的那一刻 |
| 结果 | 可量化的变化 | "效果很好" |
| 回声 | 这个人后来怎么样了（一两句） | 省略（少了真实感） |

### 三个具体性（缺一个案例就"假"）

1. **人**：有身份、有处境（"前台小林，入职四个月"）
2. **数**：金额、次数、天数、比例（"每晚 8 间空房，升级要主管签字"）
3. **时**：什么时候发生的、持续多久

### 案例页的内容槽位

- 左侧叙事（四幕，每幕 ≤2 行）
- 右侧理论面板（机制名 + 2–3 个要点 + 一句边界）
- 底部结论条（一句可复述）

**理论面板最多 2 条要点。** 3 条以上会把案例挤成配角，学生只读理论不看故事。

---

## 四、事实边界：必须写，且写在明处

### 1. 虚构案例必须声明

任何时候用了"某酒店""某平台""某健康管理中心"这类情境，都要在页脚或讲稿写：

> 教学模拟案例，人物与机构均为虚构，不对应任何真实企业事件。

不写会带来两个后果：学生当真实案例引用；听众以为是内部爆料。

### 2. 不要替真实机构"编内部对话"

真实机构名 + 编造的对话 = 事实错误。要么改成"某连锁酒店"，要么只引用公开报道的原话。

### 3. 专业内容（医学/法律/财务）宁可标"示意"

解剖图、检验流程、法条适用，宁可画示意图并标注"示意，非诊疗依据"，
也不要为了好看而改动结构。

### 4. 数据要有出处

| 数据来源 | 标注方式 |
|---|---|
| 教材/论文 | 页脚写"数据来源：XX，20XX" |
| 公开报告 | 写机构名与年份 |
| 课堂估算 | 写"课堂估算，用于讨论" |
| 编的 | **不要编**，改成定性描述 |

## 五、互动题怎么写

**结构**：题干（真实情境 + 具体数字）→ 3–4 个选项 → 正确答案 → 一句"为什么其他人会选错"。

规则：

- 题干必须有**具体角色和数字**："某体检中心 2980 元套餐三个月只卖出 17 份"，不是"某机构销售不佳"
- 错误选项要是**学生真实的误解**，不是凑数的荒谬选项
- 正确答案 ≤2 行；解释放 `hint` 或下一页
- 一节课 1–2 次足够；每次要求"先投票，再看结论"
- 答错不扣分，但要说清判断依据

反例：`以下关于健康管理的说法正确的是？A/B/C/D` —— 这是考试题，不是课堂互动。

## 六、图片：三种情况，三种做法

| 情况 | 做法 |
|---|---|
| 用户提供图 | 优先用；等比裁切，永不拉伸；压字处用单条 alpha 渐变遮罩 |
| 能生成/找到贴题图 | 只用于"承担看见"的页（案例场景、实物、地理位置） |
| 没有图 | **不要占位图**。改用无图结构（大字、对照、卡片、矩阵），并跑 `--image none` 验证 |

判断一张图该不该在页面上：**删掉它，这一页的意思会不会变？**
不会变 = 装饰 = 删。

禁止：emoji 当图标、艺术字、PPT 自带剪贴画、与内容无关的"商务人士握手"。
